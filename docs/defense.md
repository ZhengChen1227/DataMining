# 创新点说明与答辩准备

## 一分钟说明

老师，我们研究的是有限计算预算下的链接预测。共同邻居算法在没有共同邻居的节点对上都会给零分，
三跳信息可能进一步区分它们，但完整搜索会增加计算量。我们的 ABLP 先判断共同邻居是否为零，
再根据训练图中两个节点的度数，给需要扩展的候选分配三跳访问预算。
我们与固定预算方法比较，并拆开门控和度数加权做消融实验。三跳路径本身已有研究，
我们的工作是一个可实现、可核验的预算分配策略实验，结果以实际数据为准。

## 老师可能追问

**这和 Local Path 有什么不同？** LP 完整使用二跳和三跳计数；ABLP 在预设预算内只访问部分三跳组合，
并把预算集中给 CN 为零的候选。它会损失部分信息，是否值得要看效果与成本的共同变化。

**为什么按度数乘积的平方根分配？** 度数乘积是需要检查的邻居组合数；平方根减弱高阶节点占用预算的倾向。
这是一个明确可测的启发式选择，不是已证明最优的规则；均分预算消融用于检验它是否有益。

**一次访问是什么？** 检查某个 a∈N(u)、b∈N(v) 之间是否有训练边。无论命中与否都计一次。
共同邻居检查单独记录，预处理与分配成本也计入运行时间。

**相同 B 就公平吗？** 只能说总上限相同。固定预算可能留下未使用额度，ABLP 也可能因门控没有足够搜索容量。
所以必须看实际总访问次数和时间，不能单凭 B 宣称同成本更优。

**你们是不是用到了测试答案？** 算法接口没有标签参数；训练图决定所有结构特征。
验证标签只选择 epsilon，测试标签只计算最终指标。完整观测图只在划分时排除已知正边作为负例。

**为什么不直接用神经网络？** 本课题关注预算分配本身，局部算法便于明确计费和做机制对比。
这不意味着局部算法优于所有神经网络，也不把未比较的方法写成被超越的基线。

**没有显著提升怎么办？** 报告真实结果，检查是否只有低预算、特定稀疏度或零共同邻居子组受益；
如果度数加权不如均分，就承认这部分假设缺少支持，不能用改名或挑选结果替代证据。

**负例是否是真的没有关系？** 这里只知道数据集中没有观测到边；不是现实中永远不可能产生链接。
该实验是静态缺失边恢复，不能据此保证部署效果。

**为什么 1:10 也要测？** AP 依赖正例比例，而且 ABLP 的批预算分配也随候选集合改变。
敏感性实验能暴露评测构成的影响；它仍不能完全代表所有非边的实际检索任务。

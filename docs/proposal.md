# 选题书

## 题目

面向分布漂移的多变量时序异常检测：通道关系建模与测试时校准

## 问题

多变量时序异常检测的主流方法在公开基准上已经接近饱和，但这些基准有一个共同的
隐含假设：**训练段与测试段同分布，且传感器通道集合固定**。真实系统里三条都不成立：

1. 工况会切换，训练期采到的数据和上线后遇到的数据不是一回事；
2. 传感器会增删、会重新布线，通道之间的对应关系会变；
3. 传感器会漂移标定，同一个物理量读出来的数值尺度会变。

现有方法的评测体系无法回答「漂移下还剩多少性能」，更无法定位崩溃的来源。

## 现有工作的缺口

- 基准侧：TSB-AD 等新基准解决了「同分布下指标不可比」的问题，
  但没有提供可控的漂移划分。
- 方法侧：大量工作在做「更强的通道依赖建模」（图神经网络、通道注意力），
  但很少有工作检验这种建模在通道关系变化时是否是负资产。
- 对策侧：在线归一化（本仓库的 `adaptive_zscore`）是业界默认手段，
  但它只处理一阶/二阶矩的变化，对通道关系错位无能为力。

## 方法

三个组件，可独立开关，便于消融：

1. **可学习稀疏通道图**。用 top-k 稀疏化的邻接矩阵做通道间消息传递，
   并把「是否使用通道信息」交给一个可学习的门控 `gamma` 决定。
   动机：把通道关系当作可选的归纳偏置，而不是强制的结构先验。
2. **环境不变性 (V-REx)**。把训练段按时间切成 E 个环境，
   优化 `mean(risk) + λ · Var(risk)`，让表示跨工况稳定。
3. **测试时校准 (TTA)**。无标签地在测试流上重估归一化统计量，
   并对归一化层做少量自监督微调。

## 验证设计

- 数据：TSB-AD 作为主基准；SMAP / MSL / SWaT / SMD 作为经典对照；
  合成数据用于验证管线正确性。
- 协议：`none` / `temporal` / `channel` / `channel_mask` / `amplitude`，
  定义为「只动一侧、不动标签、先归一化后漂移」。
- 指标：VUS-PR 与 AUC-PR 为主，官方评测器复核；
  point-adjust F1 只作对照列。
- 统计：3 个种子 × 配对 Wilcoxon 检验。

## 预期贡献

1. 一套可控、可归因、代码化的时序异常检测分布漂移评测协议；
2. 对「通道依赖建模在漂移下是否可靠」的实证回答（正负结果都有价值）；
3. 一个把通道图、不变性学习、测试时校准组合起来的轻量方法，
   在 8GB 显存内可完整复现。

## 风险与对策

| 风险 | 对策 |
| --- | --- |
| 漂移协议被认为是人为构造 | 每条协议绑定一个具体的工程场景，并报告 `adaptive_zscore` 等强基线 |
| 通道图方法在 `channel` 下反而更差 | 这本身就是有价值的负结果，配合 `gamma` 分析给出机制解释 |
| 指标与文献不可比 | 强制使用 TSB-AD 官方评测器 |
| 提升不显著 | 3 种子 + 配对检验，把「不显著」也如实写出来 |

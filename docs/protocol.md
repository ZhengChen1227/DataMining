# 实验协议与算法定义

## 研究边界

研究静态观测图中的缺失链接恢复，不研究时间顺序上的未来预测。统一无向、无权简单图，
保留全部节点，删除自环、合并重复边；email-Eu-core 的有向邮件关系忽略方向。
没有用节点属性或邮件内容。随机移除边不保证训练图连通，孤立节点按零结构信息处理。

## 划分与候选

固定种子 42–46，各自随机打乱规范化后的边，前 floor(0.8E) 条为训练边，
接下来 floor(0.1E) 条为验证边，剩余为测试边。训练保留率 50%、75%、100% 使用同一训练边顺序的前缀。
测试及验证候选在三种保留率下完全一致。

从观测图非边抽样独立的验证、测试负例池，彼此不交叉，且不含训练、验证、测试或额外删去的真实边。
默认正负比 1:1；100% 训练保留率另运行 1:10。1:1 使用相应 1:10 负例池的前缀。
完整观测图仅用于划分和构造负例。模型只能看到训练图，计算度数、CN、邻居顺序时也只用训练边。
所有方法使用同一批候选，不按 CN 或三跳可达性筛选测试集。

## 三跳与预算

候选规范化为 u<v。对每个 a∈N(u)，逐个枚举 b∈N(v)，检查 (a,b) 是否存在。
训练图没有自环，且候选 (u,v) 是非边，因而命中的长度为三的游走在此条件下恰好对应简单三跳路径。
共同邻居枚举较小邻居集合，每次集合成员检查计为一次 CN 检查；三跳每次边成员检查计为一次访问，命中与否都收费。

邻居均按（训练度数、节点编号）升序排列。三跳惰性枚举，不构造候选笛卡尔积。
这只是确定性的访问顺序，低度优先并不保证最优；节点重编号可能改变同度邻居的截断前缀。

固定预算给每个候选 min(B,d(u)d(v)) 次访问。ABLP 只让 CN=0 且端点非孤立的候选参与分配，
权重为 sqrt(d(u)d(v))，批总额度为 M×B。按比例计算份额；达到容量的候选先领满，剩余重新分配；
最后取整并按小数余量从大到小补齐，同余量按节点对排序。零权重不参与，容量耗尽时可以不花完预算。

gate_uniform 用均匀权重但保留门控；degree_only 保留度数权重但取消门控。
两项消融与 ABLP 使用同一批总预算。各方法均使用 CN + epsilon × 已发现路径数；CN、AA 不搜索三跳。
不把截断路径数解释为完整计数的无偏估计，未访问不等于不存在。

## 选择参数与计时

每个数据集、种子、保留率、负采样比例、方法及预算条件独立在验证集选择 epsilon，
候选为 0.001、0.01、0.1；AP 同分选较小值。各个 B 是预设实验条件，不用测试集选择“最佳 B”。
默认展示 B=100 的主表，同时完整展示四个预算的曲线，防止只展示有利结果。

CPU 时间使用 process_time；实际耗时使用 perf_counter。计时覆盖邻接表构建、排序、CN、预算分配与路径搜索，
不含读取数据、选参指标计算、磁盘输出。验证和测试分别计时，主表报告测试评分时间。
不跨方法缓存 CN，以免让某个方法无偿获得预处理；总检查数 = CN 检查数 + 三跳访问数，
不等价于所有机器指令，排序与分配成本由实际时间补充衡量。
完整 LP 是相同 Python 内核下的精确参照，不代表所有优化 LP 实现的最快速度。

## 结果解释

AP 是主指标，ROC-AUC 是补充。不同负例比例的 AP 不能直接当作同一难度下的提升。
零共同邻居子组只有一个类别时不计算 AP 或 AUC，写 null 并报告人数。
标准差采用种子间样本标准差；这些随机划分相互重叠，不作五个独立真实网络理解。

有限预算方法的相同预算上限不保证实际访问次数相同；同时展示实际检查次数、耗时和 AP。
ABLP 的门控节省在有 CN 的候选上的搜索，却可能失去这些候选内部的排序能力。
较大的度数乘积仅表示更大的搜索空间，并不能证明更高的单位预算收益，这正是需要实验检验的假设。

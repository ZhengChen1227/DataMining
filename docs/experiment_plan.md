# 实验计划（8 周）

## 目标分层

| 层级 | 产出 | 说明 |
| --- | --- | --- |
| 保底 | 完整可复现的漂移评测基准 + 全部基线数字 | 课程项目要求，一周内可完成 |
| 目标 | 通道图 + 不变性 + TTA 的方法在至少两条协议上稳定优于全部基线 | 可投 workshop / arXiv |
| 冲刺 | 机制分析（学到的通道图、分数分布漂移）+ 显著性检验 + 泛化到 TSB-AD 全集 | 正会投稿要求 |

## 周计划

### 第 1 周：环境与链路
- [ ] WSL2 + torch(cu121) + `pip install -r requirements.txt`
- [ ] `python -m src.train --list` 与合成数据冒烟通过
- [ ] 跑通 `scripts/run_smoke.ps1` 的 `zscore` + `none`
- [ ] 下载 TSB-AD，确认 `data/raw/tsb-ad/` 能被加载
- 交付：环境可复现 + `docs/setup.md` 更新

### 第 2 周：基线主表
- [ ] 复现 `zscore` / `adaptive_zscore` / `iforest` / `convae` 在 `none` 下的全部数字
- [ ] 接入至少 2 个深度基线（Anomaly Transformer、DCdetector）到 `adapters/`
- [ ] 用官方评测器复核一遍，确认内部近似指标的偏差量级
- 交付：`results/summary.md` 的「同分布」列

### 第 3 周：动机实验（**整个工作的命脉**）
- [ ] 跑 `temporal` / `channel` / `channel_mask` / `amplitude` 四条协议 × 全部基线
- [ ] 产出「崩溃表」：每个基线在每条协议下的绝对下降与相对下降
- [ ] 画出关键图：异常分数在漂移前后的分布对比
- [ ] 写出可检验的假设，例如「通道置换对边缘分布无影响，因此逐点基线不变，
  而通道依赖模型掉点，说明崩溃源于通道关系错位」
- 交付：`docs/proposal.md` 里的动机一节 + 两张核心图

### 第 4-5 周：方法
- [ ] 第 4 周：只开通道图（`ours_no_graph` vs `ours`）
- [ ] 第 5 周：加环境不变性（`env_penalty`），再逐级加 TTA
- [ ] 每加一个组件就跑一次全协议矩阵，防止「同分布变好、漂移下没变」
- 交付：消融链条的完整数字

### 第 6 周：补齐与加固
